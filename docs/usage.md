# 编辑器使用指南

让 Agent 接入你的网页并打开工作台后，上方显示真实网页预览，下方是时间轴，右侧是参数面板。首次使用流程见 [README](../README.md#如何使用)。

## 时间轴与参数

每个元素有一条父级时间条，展开后可以分别调整透明度、位置和缩放等属性。

| 操作位置 | 行为 |
| --- | --- |
| 元素左侧箭头 | 展开或折叠属性轨道 |
| 父级时间条中间 | 平移整组动效 |
| 父级时间条两端 | 固定另一端，按比例拉伸或压缩组内各属性与关键帧的时间 |
| 属性轨道线段或中间曲线图标 | 平移这条属性的所有关键帧，保持节点间距 |
| 菱形关键帧 | 单独调整对应节点的时间 |
| 属性名称、关键帧或曲线图标 | 选中属性，启用右侧参数面板 |
| Shift + 点击名称、线段或关键帧 | 加入或取消多选，支持跨元素 |
| 右侧起止值 | 修改属性的起始值与结束值 |
| 曲线预设、贝塞尔把手或四个控制值 | 调整缓动；时间轴中的曲线缩略图同步更新 |
| 眼睛图标 | 启用或停用对应轨道 |
| 时间尺或播放指针 | 拖动查看对应时刻的网页效果 |
| 当前时间、时间轴范围 | 输入毫秒数调整播放位置或时间尺范围 |

未选中属性时，参数面板保留位置并显示置灰占位。滚动条会在滚动或鼠标靠近时显示。

## 多选与一起拖动

按住 Shift 点击要选择的属性，可以跨元素添加或取消选择。多选时，右侧显示已选条数，暂停单条参数编辑。

松开 Shift，拖动任意已选线段即可一起平移，保留相对时序。轨道到达时间边界后继续拖动，仍会保留多选。父级与子属性混合选择时，同一轨道只移动一次；一次整体拖动可通过一次撤销恢复。

普通点击切回单选，点击时间轴空白处清空选择。拉伸父级两端或单独拖动菱形关键帧时，会切回对应单选。

## 快捷键

| 快捷键 | 行为 |
| --- | --- |
| 空格 | 播放／暂停，支持工作台和已接入的网页预览 |
| Enter | 提交单行输入框并失焦 |
| `⌘Z` / `Ctrl+Z` | 撤销 |
| `⌘Shift+Z` / `Ctrl+Shift+Z` | 重做 |
| 左右方向键 | 聚焦关键帧、父级时间条或其手柄后，按 10ms 调整 |
| Shift + 左右方向键 | 按 100ms 调整 |

输入框、可编辑文本和已打开的交接弹窗保留正常键盘操作。中文输入法确认不会被回车提交拦截。

## 位置坐标

Position X/Y 以网页左上角为原点，表示元素左上角的页面坐标，单位为 CSS px；向右、向下为正。页面滚动不会改变坐标，编辑器面板的偏移不计入坐标。

例如，Y 为 `280 → 260` 表示元素从距页面顶部 280px 移动到 260px。

原来以位移注册的动画，在连接网页后会自动换算成页面坐标。AI 应用结果时，需要按页面布局换算回源码中的位移。数据格式和换算说明见 [项目接入指南](integration.md#页面坐标与位移换算)。

## 保存与交接

参数修改会自动保存。点击 **交给 AI → 复制给 AI**，将调整内容复制到剪贴板，然后粘贴回 Agent。复制内容包含修改摘要、补充说明，以及读取完整参数的会话、版本和本地文件位置。

剪贴板不可用时，弹窗会显示并选中可手动复制的文本。

编辑器保存的是动效参数。Agent 读取确认版本后，再修改你的项目源码并验证。你可以继续编辑草稿，下一次确认会产生新的交接版本。

同一会话从多个窗口修改时，过期窗口会提示保存冲突。请保留当前窗口，让 AI 协助处理，避免刷新后丢失尚未保存的修改。
